# 集計アーカイブ（公開）

自動集計の結果を自動コミットで蓄積する公開アーカイブです。朝のブリーフィングは含みません。

## 収録内容

| フォルダ | 内容 | 配信頻度 |
|---|---|---|
| [github-trending/](github-trending/) | GitHub 前日星標増加 Top20 | 毎日 07:00 JST |
| [jp-stocks/](jp-stocks/) | 日股 Prime まとめ（出来高増加・株価変動率 各Top50、完全版） | 東証取引時間中・毎時 |
| [weibo/](weibo/) | 微博热搜榜 Top50 | 毎日 3回（08:44／12:44／20:44 JST） |
| [yahoo-nikkei/](yahoo-nikkei/) | Yahoo!ニュース アクセスランキング前10＋日経 要聞前10（見出し・リンクのみ） | 毎日 3回（09:00／13:00／21:00 JST） |

## 出典・注記

- 日股Primeまとめ：Yahoo!ファイナンス日本株ランキング（出来高・値上がり率・値下がり率）に基づく時間差分の近似集計です。全銘柄の厳密なランキングではありません。
- GitHub星標：GitHub Trending 日榜の stars today に基づく近似順位です。
- 微博热搜：微博公式リアルタイム熱搜の転記で、出典と収集時刻を各ファイルに明記します。
- 雅虎・日経：見出しとリンクのみを収録し、記事本文は含みません。各ファイルに出典と収集時刻を明記します。
